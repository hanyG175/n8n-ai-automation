## Setup instructions
1. Import your WhatsApp support workflow JSON into n8n.
2. Create and connect credentials (use your own values):
   - WhatsApp API
   - LLM provider API
   - Optional CRM/helpdesk API
3. Configure placeholders in the workflow:
   - `YOUR_PHONE_NUMBER_ID`
   - `YOUR_WEBHOOK_VERIFY_TOKEN`
   - `YOUR_CREDENTIAL_ID`
